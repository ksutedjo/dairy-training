# Dairy Training Portfolio

Source for a portfolio and project page by Kenneth Sutedjo. It presents two side projects:

- **A training game for new dairy operators** (hygiene, GMP, CIP basics), hosted on itch.io.
- **A dairy knowledge base** covering process, quality, hygiene, maintenance and troubleshooting.

The page also introduces the author and a future consulting offer for small and medium dairy makers (soft cheese and mozzarella). Consulting is not open yet.

## How the site works

The whole site is one file, `index.html`. There is no build step. GitHub Pages serves it directly from the `main` branch.

To change it, open `index.html` on GitHub, choose the pencil icon, edit, and commit. The live site updates within a minute or two.

## Before publishing

- Replace every placeholder in `[square brackets]`.
- Remove the Draft banner at the top of `index.html`.
- Get the sample scenario and knowledge-base content reviewed by a dairy expert (and a native speaker for Bahasa Indonesia text).

## Notes

- Content is for education. It does not replace a plant's HACCP plan, SOPs, or local food safety and Halal requirements.
- This repository is public. Do not add confidential information, client data or credentials.
